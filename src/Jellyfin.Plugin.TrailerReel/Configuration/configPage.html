Trailer Reel

Maintain separate local 1080p trailer pools for regular and anime movies, then play only the matching pool before each movie.

Discovery

A free TMDb v4 read access token. It is sent only to api.themoviedb.org.

Anime movies

Japanese animated movie trailers are isolated from the regular pool and are returned only for movies inside the configured Jellyfin library.
Enter the exact Jellyfin library name, such as Anime Movies.
The anime pool is capped at 30 files and uses the same U.S. date window and 1080p requirements.

Storage and downloader

Use a persistent writable container path, such as /trailers.
Optional. Use this for cookies, a PO-token provider, proxy settings, or other site-specific yt-dlp options.
When enabled, a movie is skipped if yt-dlp cannot obtain a 1080p trailer.
Removes catalog-managed files that leave the date/genre window or whose movie is now hosted locally. Unmanaged files are never deleted.

Playback

Every queued trailer must match the movie's first genre listed by Jellyfin. If fewer unwatched matches exist, fewer trailers play instead of filling the queue from secondary genres.
A trailer is marked watched for the requesting user when it is committed to that user's preroll queue. It remains available to other users.

After saving, run Dashboard → Scheduled Tasks → Download/refresh Trailer Reel. The daily task then runs at 4:00 AM server time.
